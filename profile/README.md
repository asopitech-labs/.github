# Asopitech Labo 🧪

新しい技術や製品を試作・検証する研究開発ラボです。「まず作って確かめる」を原則に、手応えを得た実験を OSS プロジェクトや製品構想として公開しています。

An R&D lab that prototypes and validates new technologies — promising experiments graduate into OSS projects and product concepts.

## Projects

| Project | 概要 / Summary | Status |
| --- | --- | --- |
| [Nimino](https://github.com/asopitech-labs/nimino) | Nim 製の軽量クロスプラットフォーム WebView デスクトップアプリ基盤 / A lightweight cross-platform WebView desktop framework in Nim | 🚧 In development |
| [Nimculus](https://github.com/asopitech-labs/nimculus) | NimNUI + Metal の GPU ネイティブコードエディタ / A GPU-native code editor built with Nim and NimNUI | 🚧 In development |
| [Theatora](https://github.com/asopitech-labs/theatora) | アプリケーションコードを変えずに、プロバイダー・ランタイム・構成を組み替えられるコンポーザブルなバックエンド構築キット / A composable backend construction kit for changing providers, runtimes, and topology without rewriting the application（[Website](https://asopitech-labs.github.io/theatora/)） | 💡 Concept published |
| [Rhyzora](https://github.com/asopitech-labs/rhyzora) | 宣言的なアプリケーションとエンジン契約から、CLI・TUI・Web・デスクトップ・MCPインターフェースを構築するNimフレームワーク / A Nim framework for building CLI, TUI, Web, desktop, and MCP interfaces from declarative application and engine contracts（[Website](https://asopitech-labs.github.io/rhyzora/)） | 💡 Concept published |
| [Poiera](https://github.com/asopitech-labs/poiera) | AIエージェントに承認済みの実行経路・限定権限・明確な成功条件を与え、アプリケーションの変更から配備・検証までを制御するコントロールプレーン / A control plane that gives AI agents an approved execution path, limited authority, and explicit success criteria from application change through deployment and verification（[Website](https://asopitech-labs.github.io/poiera/)） | 💡 Concept published |
| [Global Executables](https://github.com/asopitech-labs/global-executables) | パッケージエコシステム横断で実行ファイル名を収集し、MCP 経由で AI エージェントに公開する公開データセット / A public cross-ecosystem dataset of executable names, collected from package ecosystems and exposed to AI agents via MCP | 🚧 In development |
| [Setup State Delivery](https://github.com/asopitech-labs/setup-state-delivery) | 設定ファイル・環境変数・ツールプロファイル・AI エージェント設定を、マシン・プロジェクト・CI・コンテナへ一貫して配送する設定配送システム / A configuration and environment delivery system that keeps working setups consistent across machines, projects, CI, and containers（[Website](https://asopitech-labs.github.io/setup-state-delivery/)） | 💡 Concept published |
| [TUBUSA/備 (Contexum)](https://asopitech-labs.github.io/tubusa-contexum-pages/) | 人材・案件・作業・売上・資金をひとつながりの仕事として扱う業務アプリケーション構想 / A business-app concept connecting people, projects, work, revenue, and cash（[English](https://asopitech-labs.github.io/tubusa-contexum-pages/en/)） | 💡 Concept published |
| [Buzz](https://github.com/asopitech-labs/buzz-nim) | 人と AI エージェントが同じ部屋で共同作業する、自分で運用できるセルフホスト型ワークスペース / A self-hostable workspace where humans and AI agents share the same rooms, on a relay you own | 🚧 In development |
| [asmati-lab](https://github.com/asopitech-labs/asmati-lab) | アスマティ・辰巳の公開実験ノート。言語・コンパイラ・FFI・ツールチェーンなどの検証を Issue と最小の実験コードとして残す / A public research notebook where experiments on languages, compilers, FFI, and toolchains are kept as issues and minimal code | 🔬 Ongoing experiments |
| [LAMINARIA](https://github.com/asopitech-labs/laminaria-rust-nim-toolchain) | Rust と Nim をひとつの計算グラフとして扱う統合ツールチェーン。依存解決・コンパイラパイプライン・バックエンド選択・成果物生成・リンク・キャッシュ・実行を、説明可能な単一のアクショングラフへ分解する / A unified toolchain that models Rust and Nim as one computational graph, decomposing dependency resolution, compiler pipelines, backend selection, artifact production, linking, caching, and execution into a single explainable action graph | 💡 Concept published |
| [GUDGEON](https://github.com/asopitech-labs/gudgeon-nif-execution-platform) | NIF プログラムの実行基盤。同じプログラムモデルを、インタプリタ実行・事前ネイティブコンパイル・デバッガによる検査・計装のすべてで扱う / An execution platform for NIF programs where one program model is interpreted, compiled ahead of time, inspected by a debugger, and instrumented（[Website](https://asopitech-labs.github.io/gudgeon-nif-execution-platform/)） | 💡 Concept published |
