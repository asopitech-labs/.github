# Code of Conduct

## 私たちの約束 / Our pledge

年齢、体型、目に見える・見えない障害、民族、性特徴、性自認と表現、経験の度合い、
学歴、社会経済的地位、国籍、容姿、人種、宗教、性的指向にかかわらず、
このプロジェクトへの参加が気持ちよく成立することを目指します。/
We want participation in these projects to be a straightforward, friendly experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race, religion,
or sexual identity and orientation.

## 基準 / Our standards

歓迎される振る舞い / Behavior that keeps this project pleasant:

- 異なる意見・視点・経験の度合いを尊重する / respect differing opinions, viewpoints, and experience levels
- 建設的な指摘を贈り、受け取る / give and accept constructive feedback gracefully
- 誤りの責任を引き受け、影響を受けた人に謝り、学ぶ / take responsibility, apologize, and learn
- プロジェクトと利用者にとって最善を考える / focus on what is best for the project and its users
- 多くの参加者にとって英語も日本語も第一言語ではないことを前提に、善意を仮定する /
  assume good faith — many contributors are not writing in their first language

受け入れられない振る舞い / Behavior that is not acceptable:

- 性的な言動・表現、性的な関心の押し付け / sexualized language or imagery, and unwelcome sexual attention
- 荒らし、侮辱・中傷、個人攻撃や政治的攻撃 / trolling, insults, and personal or political attacks
- 公私を問わない嫌がらせ / public or private harassment
- 許可のない個人情報の公開 / publishing others' private information without permission
- 職業的な場にふさわしくないその他の行為 / other conduct inappropriate in a professional setting

## 適用範囲 / Scope

Issue、Pull Request、Discussions、コードレビューを含むすべてのプロジェクト空間と、
公の場でプロジェクトを代表する場合に適用されます。/
This applies in all project spaces — issues, pull requests, discussions, and code
review — and when representing the project in public spaces.

## 違反への対応 / Enforcement

嫌がらせやその他の受け入れられない振る舞いは <https://asopi.tech/contact> から
報告してください。すべての report は速やかに、公平に確認し、報告者のプライバシーと
安全を尊重します。/
Report unacceptable behavior through <https://asopi.tech/contact>. All reports are
reviewed promptly and fairly, and the reporter's privacy is respected.

メンテナは、この Code of Conduct に沿わないコメント・コミット・コード・Issue を
削除、編集、却下することがあり、適切な場合はその理由を説明します。重大または
繰り返しの違反には、一時的または恒久的な参加禁止を課すことがあります。/
Maintainers may remove, edit, or reject contributions that are not aligned with this
Code of Conduct, and will explain moderation decisions when appropriate. Repeated or
severe violations may result in a temporary or permanent ban.
