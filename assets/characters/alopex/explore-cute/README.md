# Generated Alopex DB mascot exploration

Eight separate PNG illustrations generated with the built-in `image_gen` tool. No Pillow, SVG, programmatic drawing, compositing, or image post-processing was used; generated PNGs were copied into this directory unchanged. All use opaque navy backgrounds.

These are exploration candidates, not an approved replacement for the shipped identity. The same reference character keeps the series consistent, but it also carries forward a face that can read as a fluffy kitten. The huge tails, ruffs, snow behavior and polar setting help; the short muzzles and relatively large ears still need refinement. The outputs also contain some smooth shading despite the flat-color instructions.

Owner-review shortlist: **01 sleeping, 04 blizzard, 06 pounce, 08 chirps**, with the species caveat above. **03** is useful for the data-protection concept; **07** is a secondary environmental option. **02** and **05** need stronger fox anatomy before a final identity review.

The prompt blocks below are the exact strings sent to the tool. Reference-image inputs and transparency settings are recorded separately because they are tool arguments rather than prompt text. Scene 01 was generated without a reference; scene 02 used scene 01; scenes 03–08 used scene 02 as a character/style reference. All calls used `transparent_background: false`.
